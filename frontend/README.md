# Intelligent Doctor — 患者端（中老年友好版）

Vue 3 + Vite + Tailwind，面向中老年人：大字体、大按钮、流程简单。

## 设计原则

- **一句话说明**：告诉哪里不舒服，Agent 帮你看科、帮挂号
- **无模式切换**：用户不需要理解「咨询 / 挂号」区别
- **智能推荐默认折叠**：有需要再点「查看科室推荐」展开
- **单列布局**：聊天为主，不分散注意力

## 开发

```bash
cd frontend
npm install
npm run dev
```

## 构建

```bash
npm run build
```

产物输出到 `src/main/resources/static/`。
